Assistant personnel

Application privée à usage individuel

Cette application est un outil personnel automatisé, développé et utilisé exclusivement par son auteur pour un usage strictement privé.

Ce n'est pas un produit public. Il n'existe pas d'inscription, pas de compte à créer, et aucune autre personne que son auteur n'y a accès. Le code tourne sur un ordinateur personnel.

Pourquoi cette page existe

Cette page sert uniquement à satisfaire l'exigence de Google Cloud Console qui demande une URL de page d'accueil pour une application OAuth à usage strictement personnel.
